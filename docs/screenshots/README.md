# Screenshots

After you run the app locally, capture a few window shots and save them here with these exact names so the README gallery works:

- `dashboard.png` — status counts and follow-ups
- `applications.png` — the filtered applications table
- `detail.png` — one application with resume and status history

On macOS, open the app at http://localhost:3000, then:

1. Press `Cmd + Shift + 4`, then `Space`, then click the browser window
2. Move the files into this folder and rename them as above
